# SQL Business Analytics & Relational Database ETL

**Objective:** Extract, analyze, and visualize business intelligence from a relational SQL database to drive strategic decision-making.

**Tech Stack:** SQL (SQLite), Python, Pandas, Matplotlib, Seaborn.

**Methodology:** 
* Built an ETL pipeline to download and connect to the Chinook digital media relational database.
* Engineered advanced SQL queries utilizing multi-table `JOIN`s, `GROUP BY` aggregations, and subquery logic to analyze sales performance.
* Translated raw SQL query outputs into Pandas DataFrames and designed visual business dashboards.

**Key Findings:** 
* **Revenue by Region:** The USA market generated the highest total revenue ($523.06), followed by Canada.
* **Product Performance:** Iron Maiden and U2 were identified as the top-grossing artists via a 4-table inner join.
* **Customer Lifetime Value (CLV):** Calculated the average order value and total historical spend to identify the top 5 high-value customers.
